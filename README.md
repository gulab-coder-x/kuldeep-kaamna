# Rumit & Mahek - Gol Dhana Ceremony Invitation

This folder contains the complete, standalone, production-ready website for the digital invitation at [https://rumit-mahek.invitationmedia.in/](https://rumit-mahek.invitationmedia.in/).

## 🌐 Local Access via Apache

Your local Apache server is currently running and serving this directory directly:
- **URL**: [http://localhost/rumit-mahek/](http://localhost/rumit-mahek/)

## 📦 What's Included

- `index.html`: Optimized HTML entry point with local & web font preloads, zero tracking scripts.
- `assets/`:
  - `intro-video-2-a-H3NxSy.mp4`: Stage 1 envelope opening animation video (19.7 MB).
  - `env.mp4`: Stage 2 envelope unfold animation video (9.1 MB).
  - `jashn-e-bahaaraa.mp3`: Background theme song (10.5 MB).
  - 30+ high-resolution PNG assets (couple illustrations, floral frames, Lord Ganesha idol, scratch heart, backgrounds).
  - `index-By7nars2.js`: Application logic patched for fully relative, portable routing and asset resolution.
  - `index-Cj5ft74j.css`: Complete Tailwind styling, keyframes, and color variables.
- `fonts/`:
  - 16 Adobe Typekit font files (`.woff2`) for local typography without third-party domain locks.
  - `great-vibes.ttf`: Great Vibes cursive script font.
  - `typekit.css` & `great-vibes.css`: Local font stylesheet definitions.
- `.htaccess`: Configured for Apache with MIME type support (`.mp4`, `.mp3`, `.woff2`) and SPA fallback.

## 🛠 Source Code
